# radar-web exports

Drop the JSON downloaded from radar-web for each of the five scans here as `<id>.json` (`AC4214dbd.json`, `AC4240fff.json`, `AC4242a2f.json`, `AC4242a55.json`, `image1.json`). The file is the one radar-web's Download button writes, with `findings[{key, organ, finding, prob}]` and `organs_not_found`.

Until they exist, the tier-3 parity tests are skipped and the compare route reports the reference as pending.
